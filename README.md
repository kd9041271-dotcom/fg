# وصل | WASL Delivery

واجهة عربية RTL متجاوبة لمنصة إدارة التوصيل، بتصميم مستوحى من أسلوب أدوات بناء المنتجات الحديثة: مساحة بيضاء، بطاقات واضحة، ألوان خضراء هادئة، ولوحة مؤشرات مصغّرة.

## تشغيلها
هذا النموذج ملف HTML مستقل ولا يحتاج إلى تثبيت حزم:
- افتح `index.html` مباشرة في المتصفح.
- أو فعّل GitHub Pages من إعدادات المستودع واختر الفرع `main` والمجلد `/(root)`.

## ما تتضمنه
- صفحة تعريفية عربية متجاوبة.
- معاينة لوحة مؤشرات تجريبية.
- جدول طلبات مع بحث وتصفية تفاعليين.
- تنبيه توضيحي عند الضغط على زر التواصل.

## ملاحظات
- الطلبات والأرقام المعروضة بيانات تجريبية.
- هذه واجهة أمامية فقط، ولا تتصل حالياً بقاعدة بيانات أو تسجيل دخول أو API.
- الخط يُحمّل من Google Fonts عند توفر الإنترنت، مع خط بديل محلي.
